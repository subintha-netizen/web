# 📊 ระบบบันทึกน้ำหนัก-ส่วนสูงออนไลน์

ระบบจัดการและวิเคราะห์ข้อมูลสุขภาพนักเรียนแบบครบวงจร พร้อมเชื่อมต่อ Google Sheets

---

## ✨ ฟีเจอร์หลัก

### 1. 📈 หน้าแดชบอร์ด
- แสดงสถิติรวมจำนวนนักเรียนทั้งหมด
- แสดงจำนวนนักเรียนที่มีน้ำหนักปกติ/ผิดปกติ
- กราฟแสดงสถิติ BMI แบบ Bar Chart
- ตารางแสดงข้อมูลนักเรียนล่าสุด

### 2. 👨‍🏫 ระบบหลังบ้าน (สำหรับครู)
- **กรอกข้อมูลนักเรียน:**
  - รหัสนักเรียน
  - ชื่อ-สกุล
  - ชั้น
  - เพศ
  - น้ำหนัก (kg)
  - ส่วนสูง (cm)
  - อายุ (ปี)

- **นำเข้าข้อมูลจาก Excel:**
  - อัปโหลดไฟล์ Excel (.xlsx, .xls)
  - ดาวน์โหลด Template Excel

- **จัดการข้อมูล:**
  - เพิ่มข้อมูลนักเรียนใหม่
  - แก้ไขข้อมูลนักเรียน
  - ลบข้อมูลนักเรียน
  - บันทึกข้อมูลไป Google Sheets

### 3. 👨‍🎓 วิเคราะห์เกณฑ์ (สำหรับนักเรียน)
- **ค้นหาข้อมูล:**
  - ค้นหาด้วยรหัสนักเรียน หรือ ชื่อ-สกุล

- **สถิติและกราฟ:**
  - กราฟวงกลม (Pie Chart) แสดงสัดส่วน BMI
  - สถิติเกณฑ์น้ำหนัก-ส่วนสูง

- **ผลการวิเคราะห์:**
  - แสดง BMI และสถานะของนักเรียน
  - คำแนะนำสำหรับแต่ละสถานะ
  - ดาวน์โหลดข้อมูลเป็น Excel

### 4. 💾 ระบบบันทึกข้อมูล
- บันทึกข้อมูลแบบถาวรใน Local Storage
- เชื่อมต่อกับ Google Sheets สำหรับสำรองข้อมูล
- ข้อมูลจะยังคงอยู่แม้ปิดและเปิดใหม่

## 📋 เกณฑ์การประเมิน BMI

| BMI | สถานะ | Badge Color |
|-----|-------|-------------|
| < 18.5 | ต่ำกว่าเกณฑ์ | เหลือง |

## 🚀 วิธีการติดตั้ง

### ขั้นตอนที่ 1: ติดตั้ง HTML File
1. เปิดไฟล์ `weight-height-tracker.html` ในเว็บเบราว์เซอร์
2. ระบบจะทำงานได้ทันทีด้วย Local Storage

### ขั้นตอนที่ 2: ตั้งค่า Google Sheets (Optional)

#### 2.1 สร้าง Google Sheet
1. เปิด [Google Sheets](https://sheets.google.com)
2. สร้าง Spreadsheet ใหม่
3. ตั้งชื่อว่า "ระบบบันทึกน้ำหนัก-ส่วนสูง"
4. คัดลอก Sheet ID จาก URL (ตัวอักษรระหว่าง `/d/` และ `/edit`)

#### 2.2 ติดตั้ง Google Apps Script
1. ในไฟล์ Google Sheets ไปที่ **Extensions > Apps Script**
2. ลบโค้ดเดิมทั้งหมด
3. คัดลอกโค้ดจากไฟล์ `google-apps-script-code.gs` ไปวาง
4. กด **Save** (💾)

#### 2.3 Deploy Web App
1. กด **Deploy > New deployment**
2. เลือกประเภท: **Web app**
3. ตั้งค่า:
   - **Description:** ระบบบันทึกน้ำหนัก-ส่วนสูง API
   - **Execute as:** Me
   - **Who has access:** Anyone
4. กด **Deploy**
5. คัดลอก **Web app URL** ที่ได้

#### 2.4 อัปเดต HTML File
1. เปิดไฟล์ `weight-height-tracker.html`
2. ค้นหาบรรทัดที่มี:
   ```javascript
   const GOOGLE_APPS_SCRIPT_URL = 'YOUR_GOOGLE_APPS_SCRIPT_URL_HERE';
   const GOOGLE_SHEET_ID = 'YOUR_GOOGLE_SHEET_ID_HERE';
   ```
3. แทนที่ด้วย URL และ Sheet ID ที่ได้จากขั้นตอนก่อนหน้า
4. บันทึกไฟล์

## 📝 วิธีการใช้งาน

### สำหรับครู (ระบบหลังบ้าน)

#### 1. กรอกข้อมูลทีละคน
1. ไปที่แท็บ **"ระบบหลังบ้าน (ครู)"**
2. กรอกข้อมูลในฟอร์ม:
   - รหัสนักเรียน
   - ชื่อ-สกุล
   - ชั้น
   - เพศ
   - น้ำหนัก
   - ส่วนสูง
   - อายุ
3. กดปุ่ม **"บันทึกข้อมูล"**
4. ระบบจะคำนวณ BMI และสถานะอัตโนมัติ

#### 2. นำเข้าข้อมูลจาก Excel
1. กดปุ่ม **"ดาวน์โหลด Template"** เพื่อดาวน์โหลดแบบฟอร์ม Excel
2. เปิดไฟล์ Template และกรอกข้อมูลนักเรียนทั้งหมด
3. กดปุ่ม **"อัปโหลดไฟล์ Excel"**
4. เลือกไฟล์ Excel ที่กรอกข้อมูลแล้ว
5. ระบบจะนำเข้าข้อมูลทั้งหมดอัตโนมัติ

#### 3. แก้ไข/ลบข้อมูล
1. ดูรายการนักเรียนในตาราง
2. กดปุ่ม **"แก้ไข" (เขียว)** เพื่อแก้ไขข้อมูล
3. กดปุ่ม **"ลบ" (แดง)** เพื่อลบข้อมูล

#### 4. บันทึกไป Google Sheets
1. กดปุ่ม **"บันทึกไป Google Sheets"**
2. รอสักครู่จนกว่าจะมีข้อความ "บันทึกสำเร็จ"
3. ข้อมูลจะถูกบันทึกใน Google Sheets ของคุณ

### สำหรับนักเรียน (วิเคราะห์เกณฑ์)

#### 1. ค้นหาข้อมูลของตนเอง
1. ไปที่แท็บ **"วิเคราะห์เกณฑ์ (นักเรียน)"**
2. พิมพ์รหัสนักเรียนหรือชื่อ-สกุล
3. กดปุ่ม **"ค้นหา"**

#### 2. ดูกราฟสถิติ
- กราฟวงกลมแสดงสัดส่วนนักเรียนในแต่ละเกณฑ์ BMI

#### 3. ดูคำแนะนำ
- ตารางจะแสดงสถานะและคำแนะนำสำหรับแต่ละคน

#### 4. ดาวน์โหลดข้อมูล
1. กดปุ่ม **"ดาวน์โหลดข้อมูล"**
2. ระบบจะสร้างไฟล์ Excel พร้อมข้อมูลทั้งหมด

### Frontend

- **Lucide Icons** - ไอคอนสวยงาม

### Backend
- **Google Apps Script** - Backend API
- **Google Sheets** - ฐานข้อมูล

### Storage
- **Local Storage** - บันทึกข้อมูลในเบราว์เซอร์
- **Google Sheets** - สำรองข้อมูลออนไลน์

## 🐛 การแก้ไขปัญหา

### ปัญหา: ข้อมูลหายหลังปิดเบราว์เซอร์
**วิธีแก้:**
- ตรวจสอบว่า Local Storage เปิดใช้งานอยู่
- ลองใช้ Browser อื่น (Chrome, Firefox, Safari)
- อย่าใช้โหมด Incognito/Private

### ปัญหา: ไม่สามารถบันทึกไป Google Sheets ได้
**วิธีแก้:**
1. ตรวจสอบว่าใส่ URL ของ Google Apps Script ถูกต้อง
2. ตรวจสอบว่า Deploy Web App เป็น "Anyone" แล้ว
3. ลอง Deploy ใหม่และใช้ URL ใหม่

### ปัญหา: ไม่สามารถอัปโหลด Excel ได้
**วิธีแก้:**
- ตรวจสอบว่าไฟล์เป็น .xlsx หรือ .xls
- ตรวจสอบว่าชื่อคอลัมน์ตรงกับ Template
- ลองดาวน์โหลด Template ใหม่และใช้ Template นั้น
